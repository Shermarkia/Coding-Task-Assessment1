# Python Coding Challenges

## Overview

This folder contains three Python coding challenges completed for my CodeLab II Programming Skills Portfolio. Each program uses different programming concepts covered during the module.

## Challenge 1: CO₂ Calculator

**File:** `co2_calculator.py`

This program calculates estimated CO₂ emissions based on the distance travelled and the type of fuel used (petrol or diesel).

## Challenge 2: Alexa Joke Generator

**Files:** `alexa_jokes.py`, `randomJokes.txt`

This program responds to the command "Alexa, tell me a joke" by selecting a random joke from a text file.

## Challenge 3: Book Manager

**Files:** `book_manager.py`, `bookData.txt`

This program manages book records using Python and text file handling.

## How to Run

1. Open the project folder in VS Code.
2. Make sure Python is installed.
3. Open the Python file you want to run.
4. Click **Run Python File** or run it from the terminal.

Keep the text files in the same folder as their corresponding Python programs.

## Testing

I ran all three programs in VS Code and confirmed that they work.
